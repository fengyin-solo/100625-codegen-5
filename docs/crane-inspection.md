# 起重设备定期检验台账：权限、预警与存量迁移说明

坝顶门机、尾水门机等起重设备的定期检验，按「带归属的台账」落地。本文件写清权限模型、
预警/停用规则、实测值口径，以及存量迁移的顺序与缺项补法——这些选择由实现方拍板，定在这里。

## 1. 权限与归属（每一笔都标清）

| 角色 | 账号示例 | 能做什么 | 不能做什么 |
| --- | --- | --- | --- |
| 本单位（unit） | 值班管理员（电站运行部） | 登记/维护设备台账、执行存量迁移 | 不许录入或修改检验结论（只许看） |
| 检验机构（agency） | 检验员·省特检院、检验员·市质检站 | 为**归属本机构**且**本机构资质在有效期内**的设备录入检验结论 | 替别的机构录入（越权）、改动台账 |
| 外来账号（external） | 外来参观账号 | 只许查看 | 任何写操作一律拦下 |

拦下时一律说明理由，四道闸按顺序过（见 `frontend/src/api/crane-service.ts` 的
`submitInspectionReport`）：

1. **角色闸**：外来账号、本单位账号直接挡回；
2. **资质闸**：机构未登记资质、或资质已过有效期（如市起重机械质检站，2025-12-31 到期）挡回；
3. **归属闸**：设备的归属检验机构与当前账号机构不一致，按越权提交挡回并写明两边归属；
4. **去重闸**：报告编号已存在，按重复上传挡回，原记录不动。

归属标记落在数据上：设备行有「使用单位 / 检验机构 / 最近操作人」，报告行有「录入人 / 归属标记」，
预警行有「归属单位」，待办行有「来源」。页面顶部横幅随时显示当前账号的权限说明。

## 2. 检验周期、提前量与限值（现行版别统一口径）

- 定期检验周期：**24 个月**（门式/桥式起重机）；
- 到期预警提前量：**30 天**（`下次检验日期` 前 30 天进入「临期预警」）；
- 磨损限值：钢丝绳直径减小率 ≤ **7%**，制动衬垫磨损率 ≤ **50%**。

**实测值优先**：申报结论与实测值冲突时，按实测这一套统一取值——任一实测超限时认定结论强制为
「不合格」，申报结论只留痕（报告行的「申报结论 / 认定结论 / 取值说明」三列可见）。设备状态、
预警、跨模块待办全部跟着「认定结论」走。

## 3. 预警、停用牌与跨模块回写

- 进入提前量：生成「临期预警」（同设备同类型只留一条生效中）；
- 超过下次检验日期、或认定结论不合格：设备自动转「停用挂牌」，生成「超期停用」预警，
  同时向**闸门启闭**和**水情调度**两个入口各回写一条操作待办，操作工在那两个页面能看到
  这台门机当前不可用（不只挂在设备台账里）；
- 检验完成后：生效中的预警**收回**（保留收回时间与收回原因，不删记录），跨模块待办转「已解除」；
  历史检验报告一条不动，谁也不许盖掉历史结论（报告只增不改）。

## 4. 存量迁移（顺序与缺项补法）

迁移入口在「起重设备检验」页面的存量迁移面板，仅本单位账号可执行。顺序固定为六步：

1. **机构资质**：检验机构资质表先行在册（无资质机构后续结论无处归属）；
2. **设备台账**：缺项回填——检验周期缺省取 24 个月；无检验日期的存量设备**按投运年份回填**，
   以投运年份年中（07-01）为基准按周期滚动，取第一个不早于当天的日期作为推断的下次检验日期，
   资料来源标注「按投运年份推断」；
3. **历史报告**：纸质档案**按检验日期（发生日期）升序**逐条建档；报告编号缺失的按
   `PAPER-<设备编号>-<检验年份>` 补号；同编号重复的去重跳过，只留一条；实测与限值冲突按实测认定；
4. **重算设备状态**：按每台设备最新一份报告回写上次/下次检验日期与结论——**旧报告不顶替新状态**；
5. **预警与停用牌**：按当前日期重算临期预警、超期停用；
6. **跨模块待办**：停用设备的待办回写闸门启闭与水情调度。

**断点续传**：迁移游标（下一条待导入序号）每推进一条就落一次盘
（`hydropower-plant-om:settings` 里的 `crane-migration`）。取数中断（如某条记录的设备未建档）
后游标停在断掉的那一条，下次执行从这条接着走；已入库的记录不重复导入、**不拿旧值顶替**。
迁移完成后重复执行是空操作。

**早年只有纸质报告的建档办法**（实现方拍板）：统一按「纸质补录」建档——资料来源记「纸质补录」，
录入人记「档案管理员（补录）」，归属标记记「<检验机构>·纸质补录」；缺报告编号按上面的规则补号；
纸质上没记的实测值标「缺项（纸质未记）」，**不拿别的记录的旧值顶替**，结论按申报结论登记并在
取值说明里写明缺项。

## 5. 报表与明细一致

页面统计卡片、状态分布、导出的 CSV 全部来自同一次 `queryCraneDevices(filters)` 查询结果，
报表同明细清单始终一致；导出的 CSV 末尾附统计口径与生成时间。
